Необходимо создать интерфейс веб-приложения для ведения дневника чтения под названием Footnotes (на русском — Находки).

Интерфейс mobile-first, следует гайдлайнам Apple, поддерживает светлую и темную тему.

## Главный экран
Слева вверху аватар пользователя.
Справа вверху иконка настроек, по клику на которую появляется шторка с выбором сортировки.

Заголовок: Мои находки

Поле поиска по добавленным книгам с fuzzy-search по названию и автору.

Далее карточки книг (по умолчанию в порядке добавления), в каждой карточке:
* Опционально обложка (подтягивается с Google Books)
* Название книги
* Автор книги
* Год
* Рейтинг (звездочки от 0 до 5)

В подвале навигация:
* Мои находки
* Статистика
* Добавить находку

## Добавление книги
При нажатии на "Добавить находку" появляется форма добавления книги:
* Поле ввода названия книги
* Поле ввода автора книги
* Поле ввода года
* Радио-кнопки рейтинга (от 0 до 5)
* Кнопка "Добавить"

При нажатии на "Добавить" происходит добавление книги в список находок.

При нажатии на книгу происходит переход на экран книги для редактирования.

## Экран книги
При нажатии на книгу происходит переход на экран книги для редактирования.

## Экран статиститки
Состав экрана предложи самостоятельно


### Бекенд
Бекенд представляет собой облачную функцию в Яндекс Облаке, которая пишет данные в примаунченный в контейнер бакет в формате JSON. Код функции доступен в папке tg-cloud-bucket-storage.

### Авторизация
Авторизация осуществляется через Telegram API (используй MCP Context7 для получения необходимой документации). Внеси необходимые доработки в tg-cloud-bucket-storage.

### Технические требования
* Для создания дизайна используй соответствующий навык
* Обязательно задавай уточняющие вопросы перед реализацией
* Используй чистый TypeScript без каких-либо фреймворков
* Используй ESLint
* Для написания стилей используй CSS по БЭМ-методологии
* Никогда не используй Tailwind
* Обязательно добавляй логи в релевантных местах, используй адекватный уровень логирования
